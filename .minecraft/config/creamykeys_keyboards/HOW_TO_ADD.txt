CreamyKeys Keyboards Folder

Drop .ogg, .wav, or .mp3 files here to create a keyboard named 'single'.
Or create a folder and put sounds inside it. Subfolders are supported.
OGG must contain Vorbis audio. WAV supports mono/stereo PCM or 32-bit float.
Renaming a file does not convert its audio format.

Optional: add index.txt inside a keyboard folder to control ordering.
Each line is a relative path to a sound file. Lines starting with # are comments.
Spaces, Unicode names, uppercase extensions, and quoted paths are supported.
Extra sounds not listed in index.txt are still included.

Use Rescan Sounds Folder in CreamyKeys after changing files.
