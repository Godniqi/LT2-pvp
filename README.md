# Niqi's LT2 PvP Settings

![ofcitsniqi](ofcitsniqi.jpg)

**Minecraft 1.21.11 | Dawn Client (Fabric)**

My LT2 PvP setup, mainly focused on Mace PvP and Crystal PvP.

- **Client:** Dawn Client
- **Mod Loader:** Fabric
- **Minecraft Version:** 1.21.11
